# Asset provenance

All launch assets are original and created in this repository on July 12, 2026.

- `assets/favicon.svg`: hand-authored GemSieve funnel/gem mark.
- `assets/sieve-mark.svg`: hand-authored expanded product mark.
- `assets/og-card.svg`: hand-authored source for the social card.
- `assets/og-card.png`: rasterized from the repository SVG using local Playwright/Chromium.
- `docs/screenshots/*`: captured from the local implementation by the Playwright test.

No stock photos, third-party logos, customer marks, generated people, or external fonts are used.
